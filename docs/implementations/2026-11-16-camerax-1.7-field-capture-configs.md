**Scope:** feature (Android native camera)
**Issues/spec:** user request 2026-11-16: upgrade CameraX to the release with the new interop API; candidate configs for low light, distant + moving subject, fine detail; preview unchanged; RAW among output types.
**Date:** 2026-11-16
**Branch/PR:** `camerax-1.7-field-capture-configs`

## Scope

**In scope:**

- [x] CameraX 1.6.2 → 1.7.0-rc02 in `modules/native-identification-camera/android/build.gradle`.
- [x] Three candidate field capture configs, built through the 1.7 still-capture interop.
- [x] RAW+JPEG output, with the DNG returned as `rawUri`.
- [x] Android-only `fieldCondition` prop, selected at build time by `EXPO_PUBLIC_CAMERA_FIELD_CONDITION`.

**Out of scope / not addressed:**

- Night extension (`ExtensionSessionConfig`): replaces the session, and RAW support with it is device dependent.

## Intent

**Purpose:** give a field test drive named, comparable still-capture configs per condition, and a DNG to judge what the JPEG pipeline discards.

## Design decisions and reasoning

### Version: 1.7.0-rc02

- **Decision:** 1.7.0-rc02, the newest on Google Maven (2026-11-04). No 1.7.0 stable exists.
- **Reason:** builder `camera2Interop`, `setStillCaptureRequestOption` and `CameraInfo.cameraCharacteristics` first ship in 1.7.0-alpha03; an RC's API surface is final. The interop API is not behind an opt-in.
- **Effect on the app:** CameraX publishes same-version constraints across `androidx.camera:*`, so `react-native-vision-camera`'s 1.7.0-alpha01 pin (incl. `camera-extensions`) also resolves to rc02. Vision Camera was built against alpha01. `minCompileSdk` is 36.

### Configs touch the ImageCapture use case only

- **Decision:** builder options (`setCaptureMode`, `setOutputFormat`, `setJpegQuality`, `ResolutionSelector`) plus still-request keys via `ImageCapture.Builder.camera2Interop`.
- **Reason:** still keys override repeating keys for the still alone, so the preview is untouched. `maxDetail`/`motionPriority` still pick the session frame-rate range.

### Every value is capability-gated before bind

- **Decision:** `FieldCondition.resolve(FieldCaptureDevice)` picks the first preference the selected camera advertises. Sources: `ImageCapture.getImageCaptureCapabilities(cameraInfo).supportedOutputFormats`, `isZslSupported`, and `NOISE_REDUCTION_AVAILABLE_NOISE_REDUCTION_MODES`, `EDGE_AVAILABLE_EDGE_MODES`, `HOT_PIXEL_AVAILABLE_HOT_PIXEL_MODES`, `LENS_INFO_AVAILABLE_OPTICAL_STABILIZATION`. A missing key leaves the device default.
- **Reason:** an unsupported output format throws at bind; an unadvertised Camera2 mode is undefined.

### The three candidates

| Setting               | `low_light`             | `distant_motion`                   | `fine_detail`           |
| --------------------- | ----------------------- | ---------------------------------- | ----------------------- |
| Capture mode          | `MAXIMIZE_QUALITY`      | `ZERO_SHUTTER_LAG` → `MIN_LATENCY` | `MAXIMIZE_QUALITY`      |
| Size pool             | normal (binned)         | normal                             | high-resolution         |
| Output                | RAW+JPEG → JPEG         | JPEG                               | RAW+JPEG → JPEG         |
| JPEG quality          | 95                      | 95                                 | 100                     |
| Noise reduction       | `HIGH_QUALITY` → `FAST` | `FAST` (unset under ZSL)           | `HIGH_QUALITY` → `FAST` |
| Edge                  | `FAST`                  | `FAST` (unset under ZSL)           | `HIGH_QUALITY` → `FAST` |
| Hot pixel             | `HIGH_QUALITY` → `FAST` | `FAST` (unset under ZSL)           | `HIGH_QUALITY` → `FAST` |
| Optical stabilization | `ON` if listed          | `ON` if listed                     | `ON` if listed          |

Reasons, per condition (full text in `FieldCaptureConfig.kt` KDoc):

- `low_light`: unbinned high-resolution modes are noisier in low light; sharpening amplifies noise; the DNG keeps shadow data.
- `distant_motion`: ZSL returns the frame nearest the press. RAW is excluded: CameraX documents no ZSL+RAW behaviour, Camera2 makes ZSL reprocessing and DNG capture exclusive per request, and a DNG write lengthens shot-to-shot time. Processing keys stay unset under ZSL so CameraX's reprocess request owns them. Normal pool because the high-resolution pool "might result in slower capture times"; pinch zoom is a view zoom, so the photo stays full field for a later crop.
- `fine_detail`: most pixels CameraX offers, slowest best-quality processing, DNG as unprocessed reference.
- RAW is only requested as RAW+JPEG: upload takes the JPEG.

### RAW+JPEG capture settles on both files

- **Decision:** dual `takePicture(rawOptions, jpegOptions, …)`; resolve when both `onImageSaved` calls arrive (told apart by `OutputFileResults.imageFormat`). An error before the JPEG lands rejects; an error after keeps the photo without `rawUri`.
- **Reason:** CameraX calls back once per file in no set order; an early error may be a whole-request failure with no further callback.

## What shipped

- `FieldCaptureConfig.kt`: `FieldCondition` (three candidates), `FieldCaptureSpec`, `FieldCaptureDevice`, `FieldCaptureConfig`, `resolve`.
- `NativeIdentificationCameraView.kt`: `fieldCondition` prop (rebinds), `readFieldCaptureDevice`, `buildFieldImageCapture`, `takeRawAndJpeg`, `runningCaptureMode`; `buildSessionConfig` takes the `CameraInfo` already read.
- `CaptureTuning.kt`: ZSL fallback rule moved to `CaptureTuning.runningCaptureMode`, shared with the field configs. Behaviour unchanged.
- `NativeIdentificationCameraModule.kt`: `Prop("fieldCondition")`.
- `types.ts` / `index.ts`: `NativeFieldCondition`, `fieldCondition` prop, `rawUri`, ready-event `fieldCondition` and `outputFormat`.
- `constants.ts`: `CAMERA_FIELD_CONDITION` from `EXPO_PUBLIC_CAMERA_FIELD_CONDITION`; `useNativeCameraCapture` and `NativeCameraScreen` pass it on Android.
- Diagnostics: `session_bound` carries `field_condition` and every resolved `field_*` value (−1 = key unset); `capture_saved` carries `field_condition` and `raw_file_bytes`; RAW failures report `jpeg_saved`/`raw_saved`.
